# 企业内控合规测评平台

法务和审计部门发布反舞弊、数据安全、采购红线等合规测验，员工完成后签署学习确认。系统提供完整的学习证据链，可追溯"谁在什么时候学过"。

## 核心功能

- **测验管理**：法务/审计/管理员发布、编辑、归档合规测验（单选、多选、判断）
- **在线作答**：员工在线答题，自动评分，计时交卷
- **电子签署**：通过后输入真实姓名签署学习确认，记录时间戳、IP地址、用户代理
- **高风险岗位**：高风险岗位须达到更高分数要求（默认90分），未达标不能签署
- **学习证据链**：每份记录包含电子签名、签署时间、IP地址、证书编号，不可篡改
- **数据导出**：CSV格式导出完整学习记录，作为书面证据
- **审计日志**：所有关键操作留痕，可追溯
- **学习证明**：生成带证书编号的电子学习证明，可打印验证

## 技术栈

- 后端：Node.js + Express + SQLite（better-sqlite3）+ JWT
- 前端：React + Vite + Tailwind CSS

### 启动方式

```bash
# 1. 安装依赖
cd server && npm install
cd ../client && npm install

# 2. 初始化演示数据
cd ../server && npm run seed

# 3. 启动后端（端口 3001）
npm start

# 4. 构建前端（或开发模式 cd client && npm run dev）
cd ../client && npm run build
```

生产环境下，后端会自动服务前端构建产物（client/dist）。

开发模式：前端 `cd client && npm run dev`（端口 5173，自动代理 API 到 3001）

## 数据模型

- **users**：员工信息，含高风险岗位标识
- **quizzes**：测验，含合格线和高风险岗位要求分数线
- **questions**：题目，支持单选/多选/判断
- **quiz_records**：学习记录，含分数、开始/完成时间、用时、IP
- **signatures**：签署记录，含电子签名、签署时间、IP、证书编号
- **audit_logs**：操作审计日志

## 证据链设计

每份学习记录在签署后形成完整证据：
1. **谁**：员工姓名、工号、部门、岗位
2. **什么时候**：开始时间、完成时间、签署时间（精确到秒）
3. **学了什么**：测验名称、分类、答题详情
4. **成绩**：得分、是否通过、高风险是否达标
5. **电子签名**：本人真实姓名（与账号身份核对）
6. **技术痕迹**：IP地址、用户代理、证书编号
